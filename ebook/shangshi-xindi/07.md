# 上师心滴（7）

Samten 笔记系列 - 上师心滴 （7）

1. 以三不动为基
身不动：修行者在实修时应保持三种坐式，使身体稳定不动。这样可以使风脉自然安住，从而灭除分别念。身体的稳定是修行的基础，能够帮助修行者进入深层的禅定状态。

眼不动：修行者的眼识应保持三种看式，专注于外境，从而断除对词句的伺察意增益。通过眼识的专注，修行者能够现量见到外境，减少对外界的执着和分别。

风识（觉性）不动：修行者应依靠缓慢的呼吸，使风识安住于母子无别的法界中。通过呼吸的调节，修行者能够使觉性稳定，进入无分别的法界状态。

必要：通过这三不动的修行，修行者能够安住于本来法界中，达到内外境的稳定和觉性的不动。

2. 以三安住知定量
依外境安住：修行者通过对外境的安住，使恶缘转化为助缘。外境的安住能够帮助修行者在面对外界干扰时，保持内心的平静和专注。

依内幻身安住：修行者通过对内幻身的安住，远离迷乱之行。内幻身的安住能够帮助修行者认清自身的虚幻本质，减少对自我和身体的执着。

依密风心安住：修行者通过对密风心的安住，使分别念不生。密风心的安住能够帮助修行者进入深层的禅定状态，减少杂念和分别心的干扰。

认识梦境：修行者在安住的过程中，会经历不同层次的梦境认识。
上等精进者能够彻底断除梦境，
中等精进者能够认识梦境，
下等精进者则无有噩梦，均为善梦。

[散人注]：这里的几个窍诀是放在顿超的章节里，但这些三不动、三安住，同样适用于立断的实修。

验相显现于身语（意）中：修行者在安住的过程中，会经历四种验相的显现：
1. 法性现量时：身体如乌龟般不愿离开坐式，语言如哑人般默默不语，自心如飞禽被网捕捉般不动摇。

2. 觉受增上时：身体如病者般不愿装饰，语言如疯人般通彻无迹，自心如罹患毒病般断尽分别念。

3. 觉性如量时：身体如大象陷入淤泥般无障通行，语言如鸠盘茶崽般悦耳动听，自心如箭刺入心脏般断尽思维忆念。

4. 法性灭尽时：身体如尸陀林中尸体般无有破立之迷乱，语言如空谷中声般清净于法界中，自心于觉性自明中安住。

[散人注]：很显然，这种验相几乎在现代社会里很难实现，因此也从世间法角度来说明顿超是必须长期闭关实修的。所以说，立断是适合懒散的人，顿超是给精进的修行人。

3. 以三获得印持
外境获得自在：修行者通过对外境的安住，使外缘解脱于刹土中。
内蕴获得自在：修行者通过对内蕴的安住，使幻身解脱于光明中。
密沉性获得自在：修行者通过对密沉性的安住，使迷乱分别念自灭。

4. 以四确信说解脱量
无有希求获得佛果
担忧未得佛果之心
无有希望不转轮回
担忧转生轮回之心
